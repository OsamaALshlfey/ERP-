# رصيد

نموذج أولي عربي لنظام محاسبي للمنشآت، مبني على Python القياسي وSQLite دون اعتماديات خارجية.

## التشغيل

```sh
python app.py
```

افتح `http://127.0.0.1:8000`. عند التشغيل الأول تُنشأ قاعدة البيانات في `~/.raseed/raseed.sqlite3` ويطبع الخادم كلمة مرور المدير الأولية مرة واحدة. يمكن تحديد مسار قاعدة البيانات والمنفذ عبر `RASEED_DB` و`RASEED_PORT`.

## دورة العمل المحاسبية

1. أضف حسابات حركة نشطة إلى دليل الحسابات أو استوردها.
2. من **القيود اليومية** سجّل التاريخ والوصف وسطرين أو أكثر، واختر حساب حركة لكل سطر وحدد جانبه ومبلغه.
3. لا يُحفظ القيد إلا إذا تساوى المدين والدائن؛ ويُرحّل فورًا برقم تسلسلي للمنشأة.
4. راجع **ميزان المراجعة** لمقارنة إجماليات الحركة والأرصدة المدينة والدائنة.

تُخزن المبالغ بوحدات العملة الصغرى بدقة منزلتين عشريتين. الحسابات الرئيسية وغير النشطة لا تقبل الترحيل. لا تتوفر في هذه المرحلة مسودات القيود أو تعديلها أو عكسها أو الفترات المالية أو الفواتير أو الضرائب أو المخزون؛ لذلك لا تستخدم هذا النموذج لإعداد تقارير مالية رسمية.

## الاختبارات

```sh
python -m unittest discover -s tests -v
```

هذه نسخة تجريبية للتطوير؛ يلزم إجراء مراجعة أمنية ومحاسبية وإعداد النسخ الاحتياطي قبل أي استخدام فعلي.
